## 1. Получить ветку

В VS Code открой свою папку `software-engineering-practice`. Если есть
незакоммиченные изменения, сначала сохрани свою работу. В терминале из корня:

```powershell
git fetch origin
git switch week-10
code week-10/Week10.code-workspace
```

Если локальной ветки ещё нет, `git switch week-10` обычно создаст её с отслеживанием
`origin/week-10`. Если Git не определил это автоматически:

```powershell
git switch --track origin/week-10
```

Можно открыть `week-10/Week10.code-workspace` через File → Open Workspace from File.
Установка расширения ИИ не требуется. Нужны Node 22.12+ или 24, и Python 3.8+.

## 2. Запустить проверки и страницу

В новом терминале рабочей области `week-10`:

```powershell
cd app
npm ci
npm test
npm run typecheck
npm run lint
npm run build
npm run dev
```

Не запускай npm из `week-10`: `package.json` находится в `week-10/app`.
Команды также доступны через Terminal → Run Task.

Открой локальный адрес из терминала и добавь `/?test=1`, например
`http://localhost:5173/?test=1`. Это существующий режим демонстрации:
сейчас 09:00, занято 10:00–11:00. Он не создаёт бронирований и не сохраняет данные.

## 3. Сделать две настоящие проверки UI

Desktop: ширина примерно 1440 px. Убедись, что показана одна Demo Room.
Поставь Start 11:00 и End 12:00, нажми Check availability: ожидается
зелёное Available. Проверь, что поля, подписи и результат не обрезаны.
Сохрани PNG в `week-10/evidence/ui-desktop.png`.

Mobile: открой DevTools (F12), включи панель устройств (Ctrl+Shift+M),
выбери Responsive, ширину 390 px и высоту 844 px. Поставь 10:30–11:30:
ожидается Unavailable с объяснением пересечения Test Booking 10:00–11:00.
Проверь перенос текста, доступность кнопки и отсутствие горизонтальной прокрутки.
Сохрани PNG в `week-10/evidence/ui-mobile.png`. Подойдёт снимок через DevTools
или обычный инструмент Windows; на снимке должен быть настоящий интерфейс.

В `lab-report.md` §7.2 замени «not run» фактическими наблюдениями и шириной.
Убери завершённые проверки из списка невыполненных §7.3. В §9.3 оставь `none`
в таблице, если checker больше не выдаёт ошибок. Не пиши pass, если не проверил.
Если поведение отличается от ожидаемого, запиши отличие и сохрани доказательство.
